# 慢行产品可访问交互设计

> 模块位置：页面 `slow.html`、前端 `js/slow/*`、后端 `server/`、测试 `server/test/`
> 运行：`cd server && npm test`（21 项验收测试）；`npm run seed && npm start` 后访问 `/slow.html`

## 1. 总体架构

```
┌─ slow.html ─────────────────────────────────────────┐
│  地图视图(mapview)  列表视图(listview)  点位虚拟列表(virtlist) │
│        └──────────┬──────────────┬──────────────┘   │
│              共享查询状态 store（单一数据源）              │
│   焦点管理 focus · 播报 live · 弹层栈 dialog · 偏好 prefs  │
└────────┬───────────────────────────────────────────┘
         │ /api/*
┌────────┴─────────┐   ┌──────────────────────────────┐
│ Node API server  │──▶│ SQLite：无障碍元数据/内容版本/偏好 │
└──────────────────┘   └──────────────────────────────┘
```

## 2. 需求 → 设计 → 验收 对照

### 2.1 地图操作同步成结构化路线列表；双状态共享查询状态、同一选中项
- **设计**：`store` 持有唯一状态 `{query, routes, selectedId}`。地图与列表都是 store 的订阅视图，
  选中只有 `selectedId` 一个来源；`store.select(id)` 是唯一写入口，且只允许选中当前结果内的 id。
  从设计上（而非靠同步代码）保证两侧永远是同一选中项。
- **验收**：`frontend.test.js`「地图与列表双状态共享查询状态，保证同一选中项」——
  地图点击后列表高亮同一 id；列表点击后地图 `aria-pressed` 同步。

### 2.2 API 提供同版点位文字和替代说明
- **设计**：`poi_text` 与 `media.alt_text` 都挂在 `content_version` 上；
  `GET /api/routes/:id?version=N` 一次性返回同一版本的文字 + 替代说明，杜绝混版。
- **验收**：`api.test.js`「点位文字与替代说明来自同一内容版本」「点位懒加载分页保持同版」。

### 2.3 数据库管理无障碍元数据及用户偏好
- **设计**：`a11y_metadata`（轮椅/盲道/坡道/无障碍卫生间/语音导览/坡度）按点位存储；
  `user_preference` 以 `(user_id, key)` 为主键，带单调递增 `version` 与 `device_id`。

### 2.4 大字模式只是表现层
- **设计**：字号放在 `store.presentation` 切片，应用时只切换 `<html data-fontsize>`，
  不触发列表重渲染、不触碰 `selectedId`、不移动焦点（`prefs.applyPresentation` 内有焦点保持双保险）。
- **验收**：「大字模式只改表现层：焦点、选中、列表结构不受影响」。

### 2.5 筛选后原焦点项消失 → 可预测位置 + 说明，不回页面开头
- **设计**：`applyQuery` 在列表 DOM 重建**之前**捕获焦点项 id；重建后由 `focus.reconcileAfterFilter` 裁决：
  ① 同 id 仍可见 → 焦点恢复到重建后的同 id 项；
  ② 已消失 → 焦点移到 `#filter-status`（`tabindex=-1` 的结果摘要区，位置固定、可预测），
  并播报「原先关注的路线已不在结果中」；任何分支都不会 `focus(body)`/回页面顶部。
- **验收**：「筛选后原焦点项消失…」「筛选后原焦点项仍存在…」两项。

### 2.6 偏好跨设备同步：保留当前会话操作，旧请求不能突然改变字号或焦点
- **设计**：
  - 服务端：`PUT /api/prefs/:user` 带 `expectedVersion` 乐观并发，旧版本写入 → `409`；
  - 客户端：`prefs` 模块记录 `localVersions` 与 `sessionDirty`（本会话正在编辑的键）；
    拉取响应按序号丢弃过期结果；远端键只在「版本更新且非会话编辑中」时应用；
    应用只改 `data-*` 表现层属性，永不移动焦点。
- **验收**：`api.test.js`「偏好写入带版本：旧请求被拒绝（409）」；
  `frontend.test.js`「过期偏好响应被丢弃；远端新偏好只改表现层不动焦点」。

### 2.7 验收场景
| 场景 | 设计 | 测试 |
|---|---|---|
| 懒加载失败 | 错误行 `role=alert` + 可键盘到达的重试按钮 + assertive 播报，焦点不丢 | 「懒加载失败…」 |
| 弹层嵌套 | 弹层栈：每层独立 focus trap，Escape 只关栈顶，焦点逐层归还触发元素 | 「弹层嵌套…」 |
| 无定位授权 | 不弹窗、不抢焦点；原地展开手动起点输入并播报降级信息 | 「无定位授权…」 |
| 图片说明更新 | 拉取同版内容后原地更新 `img[alt]`（按 `data-media-id` 匹配）并播报 | 「图片说明更新…」 |
| 虚拟列表滚出 | 焦点常驻 `role=listbox` 容器，`aria-activedescendant` 指向当前项；项滚出渲染窗口被卸载时焦点不丢，键盘导航从原位置继续 | 「虚拟列表滚出…」 |

### 2.8 纯键盘完成投稿、对比、返回原列表
- **投稿**：按钮 → 弹层（自动聚焦首字段）→ 提交；422 时焦点移至错误摘要（`role=alert`），
  修正后成功 → 关闭弹层、焦点归还触发按钮。
- **对比**：列表项内复选框勾选两条 → 「对比所选路线」→ 对比表（`th scope` 完整）。
- **返回原列表**：`focus.pushContext/popContext` 记录进入前的焦点项 id 与滚动位置，
  返回时恢复；兜底落点是结果状态区而非页面顶部。
- **验收**：「纯键盘：投稿（含 422 纠错）→ 对比 → 返回原列表恢复焦点」。

### 2.9 后端拒绝发布缺少必需替代说明的内容版
- **设计**：`publishVersion` 校验 `media.alt_required=1 AND trim(alt_text)=''`，
  存在即返回 `422` + 逐条 `ALT_TEXT_REQUIRED` 错误（含 poiId/field），版本保持 `draft`；
  投稿 `POST /api/submissions` 同样强制 `mediaAlt`。
- **验收**：`api.test.js`「后端拒绝发布缺少必需替代说明的内容版」「补全替代说明后允许发布」「投稿缺少替代说明被拒绝」。

## 3. API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/routes?category=&keyword=&accessibleOnly=` | 路线列表（与前端共享查询状态同构） |
| GET | `/api/routes/:id?version=` | 同版点位文字 + 替代说明 |
| GET | `/api/routes/:id/points?offset=&limit=` | 点位懒加载分页（同版） |
| GET | `/api/a11y/:poiId` | 点位无障碍元数据 |
| GET | `/api/prefs/:userId` | 用户偏好（含版本号） |
| PUT | `/api/prefs/:userId` | 写偏好，`expectedVersion` 不符 → 409 |
| POST | `/api/routes/:id/versions` | 新建内容版本（草稿） |
| POST | `/api/versions/:vid/publish` | 发布；缺必需替代说明 → 422 |
| POST | `/api/submissions` | 投稿；缺替代说明 → 422 |

## 4. 部署

```bash
# 本地（Node 20+）
cd server && npm install && npm run seed && npm start   # http://localhost:3000/slow.html

# Docker（nginx 静态 + /api 反代到 slow-api）
docker-compose up -d --build                             # http://localhost:8080/slow.html
```
